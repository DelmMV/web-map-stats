# Задачи проекта
Формат:
- **ID** — короткий идентификатор для ссылок в коммитах/PR.
- **Статус** — `active`, `planned`, `done`.
- **Описание** — что делаем и зачем.
- **Next** — ближайшее действие.

> Все задачи ниже — только фронтенд. Бэкенд поправим отдельным планом.
