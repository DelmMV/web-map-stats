# DrawerMenu decomposition (ARCH-01)

План раскладки на подкомпоненты без изменения поведения:
- `RouteCard.jsx` — универсальная карточка маршрута с метками (дистанция, покрытие, сложность, дата), кнопками действий/видимости и поддержкой клавиатуры.
- `SavedRoutesSection.jsx` — список сохранённых маршрутов, пагинация, раскрытие описаний, действия (показать/скрыть, поделиться, опубликовать, редактировать, удалить).
- `TracksSection.jsx` — треки за день и последние треки: фильтр по дате, коллапсы, пагинация, статусы загрузки/ошибок.
- `SharedRoutesCatalogSection.jsx` — каталог общих маршрутов: карточки с деталями, пагинация, статусы загрузки/ошибок, переход к детальной карточке.

Что дальше:
- Применить эти подкомпоненты в `DrawerMenu.jsx`, постепенно перенося логику.
- После раскладки — выделить общие хелперы/хуки (пагинация, описания, кнопки действий) для переиспользования.
